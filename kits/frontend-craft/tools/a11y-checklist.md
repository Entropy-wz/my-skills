# A11y checklist (manual)

- [ ] Interactive controls have accessible names (label / aria-label)
- [ ] Images that convey meaning have alt text; decorative images empty alt
- [ ] Focus order matches visual order; no keyboard traps
- [ ] Contrast sufficient for text and UI chrome
- [ ] Errors announced / associated with fields
- [ ] Respects `prefers-reduced-motion` where motion is non-essential
- [ ] No information by color alone
