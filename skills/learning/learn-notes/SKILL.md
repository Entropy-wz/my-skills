# 大学课程：按章讲解

## 目标与范围

把课程材料变成能帮助理解、推导和应用的中文讲义，而不是逐页复述或压缩摘要。默认面向正在修读该课的大学生；深度以课程目标、课件和习题为依据，严谨但不擅自扩大成科研任务。用户指定的语言、范围、目录和深度优先。

开工时定义本次完成标准：识别所给范围内的全部章节、逐章讲清核心内容、提供可用总目录、核对来源与例题。已给足材料就直接完成，不设置逐章审批。

## 读取与组织材料

- 先查看用户指定的文件和大纲；只在相关课程目录内补充查找。没有材料时询问文件位置或课程范围，不编造该课程的章节。
- PDF、PPT/PPTX 的提取、渲染按当前环境可用工具处理；需要时读取相应的 PDF 或 presentations 技能。必须覆盖所选范围全部页面；公式、表格、图示和扫描页不能仅依赖抽取文字，应查看相关页面。旧 PPT 无法读取时尝试可用的转换工具；仍失败则说明具体缺失内容，不假装已读。
- 顺序优先采用教师大纲和课件中的章节编号，其次是课件目录，最后才用文件顺序。一个文件可以有多章，多份文件也可以属于一章。无明确章节时依据内容划分并标注“据材料划分”。
- 记录文件名与页码或幻灯片号。PDF 页码默认指文件内第几页；印刷页码不同则说明。讲解中为各节关键定义、定理和教师特定说法提供来源位置，避免虚构引用。
- 区分“课件内容”“补充解释”“材料缺失或存疑”。遇到疑似课件错误，展示原说法和核对后的解释，不能无声改写。补充知识不冒充教师要求；需要外部核实时优先教材、官方资料等可靠来源。

## 交付结构

默认保存到当前课程目录的 `学习笔记/章节讲解/`；尊重已有目录。先检查已有文件，保留用户笔记，避免覆盖无关内容。

- `00-课程总览.md`：材料与覆盖范围、课程要解决的问题、章节顺序和逐章链接、先修知识、章节依赖与建议学习路径。缺失材料单列说明，不把未讲部分标成完成。
- `01-章节名.md` 等：按章节编号生成独立讲解。每章开头链接总览，结尾链接前后章；实际编号以课程为准。

各章根据学科适配内容，不机械填空：

1. 本章解决什么问题，学完应能做什么，与前后章如何连接。
2. 必要的前置知识；遇到缺口先补到足以理解本章。
3. 按课件顺序展开知识点：先直观含义，再准确的定义、符号和适用条件，最后解释原因与用法。
4. 对核心推导给出关键中间步骤和理由；公式说明变量、单位与假设。人文社科内容改用论证脉络、背景、证据与反例，不能硬套公式。
5. 代表性例子或完整例题，展示思考过程；反例、边界情况、易混概念和常见错误随相关知识点解释。
6. 章末概念关系、简短回顾，以及少量由理解到应用的自测题。答案放在独立小节，避免紧跟题目。

图确实比文字更清楚时使用 Mermaid 或文本树，并提供文字说明，确保不支持图形渲染时仍能读懂。不能用图或名词清单代替正文讲解。

## 交付前验证

- 对照章节清单和全部材料，确认没有漏章、漏掉关键图表、只写标题或留下待补段落。
- 重新计算讲义中的例题和推导；可执行的代码示例在条件允许时实际运行。核对假设、符号、答案和适用范围。
- 检查文件确实存在、目录链接与前后章链接指向正确位置、图表和公式写法完整。
- 只将已检查的部分列为完成。材料不可读等真正障碍要准确报告，不以猜测补齐。

最终用简明中文给出总览文档入口、完成范围和确实存在的缺口；不要求用户代为验收初稿。
